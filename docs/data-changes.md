# Data changes: spreadsheet → database

Generated by `python -m cotw import-v3`. Every deviation of `data/countries/` from
the v3 spreadsheet (`cotw v3.csv`), with its source. Later edits are listed by hand
under [Changes after the import](#changes-after-the-import-applied).

## Systematic changes

| What | Old | New |
|---|---|---|
| Status values | `Souvereign Country` / `Dependency` / `Disputed` | `sovereign` / `dependency` / `disputed` |
| Region names | spreadsheet spelling (`East Africa`, `West Asia`, …) | UN M49 names as in `tags.txt` (`Eastern Africa`, `Western Asia`, …) |
| Country label of dependencies | parent ISO code (`FR`, `GB`, …) | dropped, derivable from `dependency_of` |
| Country label of disputed entries | `disputed` / `umstritten` | dropped, derivable from `status` |
| Long form | `EN Long From` / `DE Langform` | `formal_name.{en,de}`, empty cells omitted |
| Capital labels | free text | `role` (machine-readable) + `label.{en,de}` (display text, unchanged) |
| Borders | ISO-2 codes B1–B14 | COTW ids, recomputed from Natural Earth land adjacency |
| Capitals | names only | + Wikidata QID and coordinates |

## Natural Earth reconciliation

Source: Natural Earth ne_10m_admin_0_map_units v5.1.1 (https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_0_map_units.zip), public domain. Map units without an ISO code were folded into the entry that
controls them de facto:

- `CNM` → CY: UN buffer zone in Cyprus
- `CYN` → CY: Northern Cyprus: de facto separate, but not an ISO entity; folded into Cyprus
- `ESB` → GB: Dhekelia sovereign base area: UK territory on the island of Cyprus
- `KAS` → IN: Siachen Glacier: Indian-administered, de facto rule
- `KNX` → KR: Korean DMZ, southern half
- `KNZ` → KP: Korean DMZ, northern half
- `SOL` → SO: Somaliland: de facto separate, but not an ISO entity; folded into Somalia
- `SYU` → SY: UNDOF zone on the Golan Heights, Syrian side
- `USG` → US: Guantanamo Bay naval base: US-controlled under lease, de facto rule
- `WSB` → GB: Akrotiri sovereign base area: UK territory on the island of Cyprus

Ignored map units (no entry of their own, no effect on any border): Antarctica (ATA), Bajo Nuevo Bank (Petrel Islands) (BJN), Bir Tawil (BRT), Paracel Islands (PFA), Scarborough Reef (SCR), Serranilla Bank (SER), Southern Patagonian Ice Field (SPI), Spratly Islands (PGA).

Manual overrides of the computed adjacency (`data/overrides/borders.yaml`):

- add BW–ZM: Botswana and Zambia share a ~150 m land border at the Kazungula quadripoint (border agreement 2013, Kazungula Bridge 2021); Natural Earth draws a Namibia–Zimbabwe contact there instead.
- add CN–MO: Macao borders Zhuhai (Portas do Cerco / Cotai) by land; Natural Earth 10m draws Macao without a shared boundary line. The spreadsheet lists CN for MO, and the issue asks for symmetry with HK/MO.
- add CA–GL: Since the 2022 Canada–Denmark agreement Hans Island is split between Canada and Greenland, creating a land border; Natural Earth 5.1.1 still assigns the whole island to one side.
